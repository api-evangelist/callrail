# CallRail

> CallRail is a call tracking and conversation intelligence platform that attributes phone calls, texts, and form fills to marketing campaigns, and applies AI transcription, sentiment, and lead scoring to inbound conversations. The CallRail v3 API is a REST/JSON interface over accounts, companies, trackers, calls, texts, form submissions, leads, users, and integrations. CallRail also ships a hosted Model Context Protocol server and a documented webhook event surface.

## Agent surfaces

- [CallRail MCP server](https://apidocs.callrail.com/#mcp): Hosted, remote MCP server with 36 tools (22 read, 14 write), OAuth 2.0 login, and setup instructions for Claude.ai, Claude Desktop and ChatGPT. The endpoint URL is issued per account by CallRail and is not published.
- [Webhooks](https://apidocs.callrail.com/#webhooks): Ten event types — Pre-Call, Call Routing Complete, Post-Call, Call Modified, Outbound Post Call, Outbound Call Modified, Text Message Received, Text Message Sent, Form Submission, Convert Assist Complete. HTTP POST, JSON body, HMAC-SHA1 `Signature` header. No retries.

## Conventions

- Pagination: offset (`page`, `per_page`; response `page`/`per_page`/`total_pages`/`total_records`) on all collections; relative pagination (`relative_pagination`, `offset`; response `next_page`/`has_next_page`) on Listing All Calls only.
- Field selection: `fields=a,b` sparse fieldsets. Several fields (`person_id`, `sentiment`, `transcription`, `zip_code`) are only returned when explicitly requested.
- Sorting: `sort` + `order` (`asc`|`desc`). Filtering and searching are per-endpoint.
- Integration identity: third-party platforms should send `Request-From: your_software_name`.
- Idempotency: none. Retrying a write can place a second call or send a second text.
- Rate limits: 1,000/hour and 10,000/day general; SMS send 150/hour, 1,000/day; outbound call 100/hour, 2,000/day. HTTP 429 on exhaustion, with no rate-limit or Retry-After headers.
- Data retention: Communication Records are deleted after 25 months; requests outside that window error.

## Notes for agents

- There is no sandbox or test mode. Every write hits production: `POST /v3/a/{account_id}/calls.json` places a real phone call and `POST /v3/a/{account_id}/text-messages.json` sends a real SMS that is billed and carrier-regulated.
- Transcript fields require a Premium Conversation Intelligence subscription and return null otherwise.
- Resolve the account first — `GET /v3/a.json` — then use that `account_id` in every subsequent path.
